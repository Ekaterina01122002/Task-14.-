# Three Bags Game 

**Описание**: Этот проект реализует игровой автомат с использованием паттерна "Цепочка обязанностей" (Chain of Responsibility) для обработки игровых событий. Игроку предоставляется возможность выбирать один из нескольких мешочков, в надежде на выигрыш. Игра предусматривает различные сценарии исхода: выигрыш, проигрыш, шанс на бесплатную попытку.

  - **Технологический стек**: Java (JavaFX) — основной язык и библиотека для создания графического интерфейса.  
Программное обеспечение является самостоятельным настольным приложением (standalone), не требует сторонних фреймворков или интеграции в другие экосистемы.

**Скриншот рабочего окна приложения**: окно игрового автомата с визуализацией монет, игрового процесса и интерфейсом пользователя.

## Зависимости
Для корректной работы приложения необходимо наличие следующих зависимостей:

1. Java Development Kit (JDK)
  • Версия: Java 11 или выше (рекомендуется Java 17+)
  • Более ранние версии Java (до 11) не поддерживают современные возможности JavaFX, используемые в проекте.

2. JavaFX
  • Версия: JavaFX 17 или выше (совместима с JDK 11+)
  • JavaFX больше не входит в стандартный JDK и должен быть установлен отдельно.
3. Среда разработки и сборки
• IntelliJ IDEA, Eclipse, NetBeans — любая IDE c поддержкой Java и JavaFX.
• Инструмент сборки (опционально):
• Maven или Gradle для автоматической загрузки зависимостей JavaFX и удобства управления проектом.


## Установка

Для начала работы необходимо:
1. Склонировать репозиторий с исходным кодом проекта   git clone <https://github.com/Ekaterina01122002/Task-14.-.git>
2. Открыть проект в любой современной Java IDE (например, IntelliJ IDEA), убедившись в наличии установленного JDK версии 17 или выше.
3. Собрать проект через систему сборки Maven.
4. Запустить приложение с помощью команды: mvn javafx:run
5. После старта приложения откроется графический интерфейс, где доступны вкладки для работы с книгами, журналами, читателями и операциями выдачи/возврата.

## Проблемы
1. Совместимость с Java и JavaFX:  
  • Приложение требует JDK 11+ и отдельной установки JavaFX 17+. На старых системах или при неправильном подключении библиотек возможны сбои или отсутствие графического интерфейса.
  • При запуске в IDE могут быть сложности с указанием путей к модулям JavaFX (особенно в IntelliJ IDEA, Eclipse).

2. Файлы-ресурсы:  
  Отсутствие или повреждение изображений в папке resources/images приведет к ошибкам отображения (пропадут анимации, интерфейс станет неполноценным).

3. Графика и производительность:  
  • Высокое разрешение или частота анимаций могут нагружать слабые ПК или ноутбуки.
  • При запуске на системах без аппаратного ускорения JavaFX — возможны лаги и снижение плавности.
